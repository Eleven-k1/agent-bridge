# M0/M1 开源实现调研

日期：2026-08-30

本记录只服务于 M0/M1 的实现边界评估。当前实现未复制、导入或运行以下项目代码，也未因此选择任何框架或依赖。

## 现场验证结果

本机对 `https://github.com/All-Hands-AI/OpenHands` 和 `https://github.com/langchain-ai/langgraph` 的 HTTPS 请求均返回“无法连接到远程服务器”。因此许可证、维护状态、发布记录和安全公告均**未现场验证**；以下“公开声明”仅来自本项目已确认的正式架构文档，不能视为本次在线核验结果。

| 项目 | 可借鉴范围 | 许可证信息 | 维护状态 | 安全风险 | Windows 适配成本 | 本轮决定 |
|---|---|---|---|---|---|---|
| [LangGraph](https://github.com/langchain-ai/langgraph) | 有状态流程、暂停/恢复、人机介入节点 | 正式架构文档记录其官方仓库声明 MIT；未现场验证 | 正式架构文档记录为可参考项目；未现场验证发布活跃度 | 若直接绑定框架状态、检查点或消息格式，会把 M0 公共契约锁定到第三方并扩大恢复面 | Python 可运行于 Windows，但依赖树、事件循环与持久化实现需要单独核验 | 不引入。以标准库 `Protocol` 和纯状态值实现首阶段 M1，保留替换空间。 |
| [OpenHands](https://github.com/All-Hands-AI/OpenHands) | 受控编码工作区、操作审计、会话追踪 | 正式架构文档记录 SDK/CLI 为 MIT、其他部分含 source-available 授权；未现场验证 | 正式架构文档记录为可参考项目；未现场验证发布活跃度 | 代码执行、容器、工作区访问和复杂授权边界不适合直接带入第一阶段；许可证须逐组件复核 | Windows 本地进程、隔离执行与容器路径存在额外适配、维护成本 | 不引入。M1 仅通过 M2-M5 的端口依赖，不直接访问文件、Shell、Git 或模型 SDK。 |

## 结论

1. 本轮未采用外部运行时依赖，避免在网络不可达且许可证未现场核验时引入供应链和兼容性风险。
2. 后续若实际复用项目或添加框架，实施方必须在联网后核验拟用版本的 LICENSE、维护信号、依赖安全公告、Windows 支持和替换成本。
3. M0 v0.5.1 是唯一公共契约来源；开源项目只能提供内部实现参考，不能覆盖公共状态、审批、审计和恢复语义。
