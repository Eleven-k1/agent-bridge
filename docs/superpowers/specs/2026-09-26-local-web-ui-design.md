# 本机 Web UI 设计

**日期：** 2026-09-26  
**状态：** 待用户评审  
**目标：** 将现有 React 工作台以本机浏览器 Web UI 形式交付，并提供不显示黑色控制台窗口的双击启动方式。

## 1. 交付目标

用户双击 `web-ui/start-web.bat` 后，系统在后台启动本机 Web 服务并打开浏览器访问 `http://127.0.0.1:5173`。用户双击 `web-ui/stop-web.bat` 后，后台停止本项目启动的服务。启动、停止和测试过程不主动显示命令窗口。

## 2. 运行架构

```text
start-web.bat
    ↓ 隐藏启动
本机 Web 服务 127.0.0.1:5173
    ↓ 浏览器 HTTP/WebSocket
现有 agent_bridge.app TCP/NDJSON 服务
    ↓
OpenAI 兼容中转 http://127.0.0.1:8080
```

Web 服务只监听 `127.0.0.1`，不接受局域网连接。它负责静态网页、浏览器会话和消息转发，不复制任务状态机、模型网关���事件持久化或安全门禁。现有 `agent_bridge.app` 继续作为业务入口。

## 3. Web UI 功能

Web 页面复用现有 React 工作台的交互和状态模型，提供：

- 本机服务连接状态。
- `/v1/models` 对应的刷新模型操作。
- 模型发现失败后的手动模型名输入。
- 真实模型任务提交到 `/v1/chat/completions`。
- 临时流式文本、M5 正式事件、最终状态和脱敏错误展示。
- Fake 任务和 Fake Tool 入口，供回归验证使用。

浏览器只接收脱敏后的连接状态、模型列表、临时帧和正式事件；不接触 TCP 会话凭据、API Key、项目文件、Shell 或工具执行接口。

## 4. 浏览器适配层

新增本机 Web 适配服务：

- `GET /` 和静态资源返回 React 构建产物。
- `GET /health` 返回服务状态，不包含会话凭据。
- WebSocket 连接建立后，服务为该浏览器会话创建到 `agent_bridge.app` 的本地连接。
- 浏览器消息仅允许模型刷新、真实任务、Fake 任务和 Fake Tool 命令。
- 后端事件和帧按原顺序转发到浏览器。
- 浏览器断开时关闭对应 TCP 连接，不影响其他本机 Web 会话。

适配层不允许任意 TCP 地址、任意命令类型或任意文件路径透传。

## 5. 启动与停止

交付目录：`web-ui/dist/`、`web-ui/server/`、`web-ui/start-web.bat`、`web-ui/stop-web.bat`、`web-ui/README.md`。启动脚本使用隐藏后台方式运行服务，等待 `/health` 可用后打开默认浏览器；重复启动时复用已运行服务。停止脚本只停止带有本项目标识的服务进程。

## 6. 错误处理

后端未启动时显示本机服务不可用；中转不可用时显示脱敏网络、超时或协议错误；模型发现失败时保留手动模型输入；WebSocket 断开时清空临时流式层但保留正式事件；无效浏览器消息返回固定输入错误。

## 7. 测试与验收

后端测试覆盖健康检查、静态页面、WebSocket 转发、非法消息拒绝和断开清理。桌面端现有测试继续通过。新增启动脚本检查重复启动、健康等待、停止范围和隐藏窗口属性。完成前运行后端 pytest、桌面端 Vitest、TypeScript 检查和 Electron 构建，并人工双击启动脚本验证浏览器访问、模型刷新、手动模型和停止流程。

## 8. 明确不在范围内

局域网或公网访问、用户登录、API Key/OAuth、其他模型协议、真实文件修改、Shell、Git、下载、安装依赖以及替换现有 Electron 入口。
